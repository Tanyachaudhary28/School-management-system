# School Management System

A full-stack MERN (MongoDB, Express.js, React, Node.js) application designed to manage school operations, student data, and administrative tasks.

---

## Features
- Frontend UI: Built with React for a responsive and user-friendly experience.
- Backend API: Powered by Node.js and Express.js to handle application logic and routing.
- Database: Uses MongoDB and Mongoose for data storage.
- Environment Configuration: Secure database connectivity using environment variables (`.env`).

---

## Tech Stack
- Frontend: React, HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB Community Server

---
